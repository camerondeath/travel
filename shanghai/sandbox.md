# Shanghai sandbox

Append-only. One line each. The site reads this file directly and groups by bucket.

Format:  `- [ ] YYYY-MM-DD | bucket | pointer | why`

- bucket is anything: food, room, bar, walk, buy, read. Lowercase. It becomes a heading.
- pointer is a URL, an @handle, or an address. URLs auto-link.
- why is one line. Written for you in a month, when you have forgotten.
- Mark `- [x]` when it has been decided on, either way. Don't delete it.
